# Debian copyright review

The public source snapshot `3adbdb36ad886396ad6267cd706c84bea6d35b99`
contains 393 tracked files, no vendored dependency sources and no logo image.
`source-copyright-review.json` inventories each path and SHA-256. Repository
LICENSE, source headers, copyright/license keyword results, source file types,
package metadata and the seven retained third-party legal documents were
reviewed. A license scanner's UNKNOWN for a project file without its own header
is covered by the repository Apache-2.0 grant, not treated as a scanner pass.

`debian/copyright` now covers project source and Debian packaging separately.
Each retained legal document has a more specific paragraph and its complete
terms; musl's composite attribution blocks remain intact. The artwork notice
credits Chromium and Rezonansowy without claiming that the image is packaged.
These Fedora legal documents do not turn this unbundled source into a vendor
archive or change the project-source license.

The Debian executable must retain the copyright documents belonging to its
actual statically linked Go sources, including the Go runtime. At package time,
`debian/collect-linked-copyright.py` enumerates `go list -deps`, resolves each
compiled source directory back to its installed Debian owner (including copied
legacy-module sources), and installs complete unmodified copyright documents
plus exact source/binary identities and SHA-256 values under
`/usr/share/doc/topo/linked-licenses/`. Missing ownership or notice files fail
packaging. `Static-Built-Using` is generated by Debian's Go helper.

The source inventory is complete for the pinned snapshot. The binary notice
manifest and its review require a successful native build with the final chosen
libraries; no source-only scan substitutes for that remaining check. New source
or changed dependency packages require a fresh inventory/notice review.
