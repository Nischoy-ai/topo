# Validation evidence

These records retain tested versions, dates, source commits and coverage.
Use the [installation guides](../README.md#install-and-operate) for setup.

| Area | Record |
| --- | --- |
| XML installation, indexes and configuration upgrade | [ServiceNow package validation](../servicenow-validation.md) |
| Worker runtime and authorization | [Managed worker evidence](servicenow-worker.md) |
| Signed package channels and installation | [Distribution evidence](distribution.md) |
| CI reconciliation and repeat scans | [IRE evidence](servicenow-ire.md) |
| Security findings and patch baselines | [Security review](../security-review.md) |

Real-system runs, simulation and independent security retests are distinct
forms of evidence. Historical successful scans retain their original dates
and dependencies; they do not establish current vulnerability status.
